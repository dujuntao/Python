# Artifact and Dataset License Notes

This anonymous review artifact contains code, metric contracts, configuration files, derived benchmark summaries, and derived score-file outputs for review.

## Code and artifact materials

The code and derived artifact materials are intended for anonymous peer review and reproducibility checking. For camera-ready or public release, attach the final project license selected by the authors and keep the same metric contract, manifests, scripts, and derived results available under that license.

## Third-party datasets

Third-party raw datasets are governed by their upstream terms. This package documents dataset terms in `results/dataset_license_audit/dataset_license_audit.csv` and avoids republishing raw data where fetch-on-demand is safer, especially for ACS/Folktables public-use microdata.

## Derived outputs

Packaged outputs are derived audit summaries, per-example prediction/score files, accepted-mask summaries, figures, and table source data used to reproduce the submitted claims. They are included for review under the same anonymous-artifact boundary above.
